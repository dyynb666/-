# 微信兼容性核验

生成器只输出可直接粘贴的 HTML 片段，所有内容样式都位于元素的 style 属性中。预览页的 CSS 和复制脚本位于片段外部，不会进入剪贴板的 HTML。发布流程按“提交、解析、受约束重排、母版渲染、自查放行”五步执行。

本地验证会拒绝 style/script 标签、class、ID、事件属性、CSS 变量、定位和动画等高风险内容，并检查图片宽度、正文行距、来源/责编/日期落款。若输入带 source_paragraphs，还会检查每个排版块和导语是否有可回溯锚点。

发布前仍须在目标公众号后台进行人工实测：

1. 从 preview.html 点击“复制可粘贴 HTML”，粘贴到一篇测试图文。
2. 保存后重新打开编辑器，确认标题、正文段落、重点提示、引用块和落款仍保留。
3. 在手机微信预览，确认没有横向滚动，图片不溢出，强调色克制且文字可读。
4. 确认图片已经在公众号后台上传或替换，且来源、责编、日期正确。

不同公众号后台版本和粘贴路径的过滤规则会变化；因此本地校验不能替代这一步实测。
